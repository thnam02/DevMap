# Root causes: the 5 xarray / sphinx pairs NameRTS's metric counts unsafe (Proviso v2.3)

Method: the edited functions were found by comparing syntax trees at the parent and the commit (research/v2/trace_changed.py). The missed test file was then run at the parent under a sys.monitoring tracer, recording per test whether an edited function ran during the test, only before tests (import or collection), or not at all.
- **xarray:** traced here with numpy 2.5 and pandas 3.0, xarray at its 2025 commits, and pytest's warnings-as-errors switched off (`-o filterwarnings=`). The run is meaningful: 459–460 of 536 test_dataarray tests pass and 20 of 21 test_strategies tests pass. The skips here are a superset of the PC's (75 here vs 24 on the PC). The extra ones are dask, sparse, pint, bottleneck and numexpr tests, none of which reaches the edited code (see below).
- **sphinx:** not run here, because its dependencies (docutils, babel, sphinxcontrib-*) aren't installed. The conclusion comes from the PC's verification rows and the test file, so it is labelled *inferred*.

## Summary
- **Four pairs: tests skipped in this environment.** NameRTS's ground truth, recorded where iris or graphviz was installed, lists a file whose relevant tests are skipped in ours (xarray: 2 pairs, iris; sphinx: 2 pairs, graphviz). Proviso records what runs, and a skipped test runs nothing. On a machine with iris or graphviz installed, those tests would record and be selected. This is an environment difference, not a Proviso rule.
- **One pair: start-up-only contact, identical import-time state** (xarray 7a654ad54a). The edited function runs only while modules are imported, and the edit doesn't change behaviour.
- **No Proviso recording gap** was found in these 5 pairs. This matches the PC reruns: 0 outcome changes in all 5.
- **xarray's `import_state_changed` lists only lock objects** (`HDF5_LOCK`, `NETCDFC_LOCK`, `SerializableLock._locks`). They appear in both xarray pairs whatever the edit, so they look like per-run identity noise rather than a real change. That's worth a separate check, but it doesn't bear on these misses: Proviso selected 42, 11 and 9 files, not the full suite.
